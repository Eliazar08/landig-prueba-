# Tori Logística

Landing page creada con [Astro](https://astro.build/) y [Tailwind CSS](https://tailwindcss.com/).

## Requisitos
- Node.js 18+

## Instalación
```bash
npm install
```

## Desarrollo
```bash
npm run dev
```

## Build
```bash
npm run build
```

## Despliegue
El contenido generado en `dist/` puede desplegarse en servicios como Vercel o Netlify.

## Créditos
Proyecto de ejemplo para la empresa ficticia **Tori Logística**.
